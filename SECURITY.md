# Security status

Lantern is an experimental preview with no external security audit. Do not use it for safety-critical or high-risk communication.

Please report vulnerabilities privately through GitHub's security advisory reporting if the repository owner enables it. Otherwise contact the repository owner without publishing secrets, exploit payloads or other users' data in a public issue. Do not assume a private reporting channel is configured until GitHub confirms it.

See docs/THREAT_MODEL.md for the supported threat model and known gaps. Never attach private vaults, passphrases, raw identity keys or location histories to issue reports.
