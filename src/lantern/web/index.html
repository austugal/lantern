    CLEAR BY DESIGN

    Know what’s happening.

    Connect two computers

    1. Run Lantern on both computers and join the same LAN, Wi-Fi or hotspot. The network can be offline.
    2. Unlock each vault. Under Your circle, create an invitation with that computer’s LAN IPv4 address.
    3. Exchange invitations in both directions. Preview them and compare all six safety-number groups before pairing.
    4. On each person’s card, choose “Allow messages”. Both sides must explicitly allow incoming messages.
    5. Send a message. An encrypted receipt changes its status to Received. If it stays unconfirmed, check the other app, permissions, firewall and hotspot client isolation.

    Your vault

    Identity keys, paired public identities and consent state are encrypted with your passphrase using scrypt and authenticated encryption. No password reset exists. Messages, positions, trails and waypoints are not saved by this desktop preview. Local administrator access or malware can still compromise an unlocked app.

    Location and timers

    Location sharing lasts at most 15 minutes and stops when the page is hidden or stops responding. Guardian permissions are separate. Check-in timers run in the desktop process; computer sleep, shutdown, denied location or an unreachable peer can prevent delivery. Coarse coordinates and GPS accuracy are estimates, not guarantees.

    What is not here yet

    No Android APK or iOS app, BLE/LoRa adapter, kilometre-range guarantee, full double ratchet, push notifications, or external security audit. The earlier mesh tests simulate radio links. This app uses your existing LAN.

    No surprise access

    No scanning nearby phones. No account scraping. No cloud relay. Only explicit invitations and expiring permissions. A recipient may keep screenshots or other copies even after a message disappears.

    Network and lock controls

    The interface listens only on 127.0.0.1 and requires a private token. Its URL is for this computer only; never share it. The UDP transport listens on the port shown at the top. Allow it only on a trusted private network. Locking closes UDP and cancels timers. Reopen invitations after unlocking because your UDP port may change.
