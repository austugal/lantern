## Title

Lantern: an open-source mobile-first nearby messaging preview for colleagues without internet

## Post

I’m building Lantern to explore a practical problem: how can nearby colleagues exchange routine requests when internet access is unavailable?

My background is hospitality technology. Hotel housekeeping and maintenance teams are an example, but the same need can arise at events, in warehouses and on field sites.

The preview supports one-to-one text messaging, app receipts, optional disappearing messages, consent-based location sharing, local waypoints and short in-app help. A searchable offline guide includes a staff-request template. A separate Windows/Mac/Linux desktop version works over a shared local network.

Android has a downloadable testing APK. The iPhone code builds successfully, but installing it needs Apple signing. Mobile currently works Android-to-Android or iPhone-to-iPhone with both apps open. Cross-platform groups and background messaging are not implemented. Physical-device range and reliability testing is still outstanding, and it is not a replacement for emergency communications.

Code, instructions, test results and downloads: https://github.com/austugal/lantern
